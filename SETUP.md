# 🚀 Setup — Bahrian's GitHub Profile

Everything here goes into **one special repo** named exactly like your username:
`ProfessorEngineergit/ProfessorEngineergit`
(A repo whose name matches your username is the "magic" repo GitHub shows on your profile.)

---

## 1. Create the special repo
1. Go to **github.com/new**
2. Repository name: **`ProfessorEngineergit`** (exactly — GitHub will show a banner ⭐ "you found a secret!")
3. Set it to **Public**, tick **"Add a README file"**, create.

## 2. Add the files
Put these in the repo:

| File | Where it goes |
|------|----------------|
| `README.md` | repo **root** (replace the default one) |
| `header.svg` | repo **root** |
| `snake.yml` | `.github/workflows/snake.yml` |
| `3d-contrib.yml` | `.github/workflows/3d-contrib.yml` |

Easiest way: open the repo → **Add file → Upload files** → drag them in. For the two
workflow files, type the path `/.github/workflows/snake.yml` when creating the file and
GitHub will make the folders for you.

## 3. Turn the engines on (run the workflows once)
The snake and the 3D calendar are **blank until their workflow runs once.**
1. Go to the **Actions** tab of the repo.
2. If prompted, click **"I understand my workflows, enable them."**
3. Click **GitHub-Profile-3D-Contrib** → **Run workflow**.
4. Click **Generate Snake Animation** → **Run workflow**.
5. Wait ~1 minute, refresh your profile. 🎉

After this they auto-update on a schedule (snake every 12 h, 3D once a day).

---

## What updates automatically vs. live
- **Live every page-load** (no waiting): stats card, streak, top languages, trophies,
  typing subtitle, profile-view counter, and your `header.svg`.
- **Generated by Actions** (need the one-time run above): the 🐍 snake and the 🌌 3D calendar.

---

## Optional upgrades
- **Include private-repo commits** in the 3D calendar / stats:
  1. Create a token at **Settings → Developer settings → Fine-grained tokens** (read-only, your account).
  2. Add it as a repo secret named `PROFILE_TOKEN` (repo **Settings → Secrets → Actions**).
  3. In `3d-contrib.yml`, swap `GITHUB_TOKEN` for `${{ secrets.PROFILE_TOKEN }}`.
- **Change the profile picture:** Settings → Profile → upload a square image
  (an EHT black-hole photo from ESO, or a NASA render — both free to use).
- **Recolour anything:** the stat cards take `&bg_color=`, `&title_color=`, etc. in the URL.
  The header colours live in `header.svg` (search for `#ff8a3c`, `#ffce7b`, `#0b1026`).

---

## Tweaking the header text
Open `header.svg` and edit the `<text>` lines near the bottom — name, age, city,
and the `science / technology / the next big thing` line are all plain text you can change.
